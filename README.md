# Prawko — бесплатный тренажёр теории на права кат. B (PL)

Тренажёр на **официальной** базе вопросов Министерства инфраструктуры РП.
Министерство публикует её бесплатно вместе с правильными ответами и мультимедиа —
платные приложения продают не базу, а обёртку.

Источник: https://www.gov.pl/web/infrastruktura/prawo-jazdy

## Что внутри

| | |
|---|---|
| Каталог | `KATALOG_dla_kandydatów_na_kierowców_072026.xlsx`, выпуск 07.2026 |
| Вопросов всего | 3518 (все категории) |
| Категория B | **2134** — 1749 базовых (TAK/NIE) + 385 специалистических (A/B/C) |
| Медиа кат. B | 920 видео + 780 картинок, **956 МБ** после перегона (было 9,5 ГБ) |
| Языки | польский + подсказка на украинском / английском / немецком (из самого каталога) |

Из 2135 вопросов категории B исключён один (№13074): каталог ссылается на
`5-9.2021.wmv`, а в архивы министерство выложило только `5-9.2021 bis.wmv` —
это другой клип. Вопрос вида «czy w tej sytuacji…» без своего видео
неотвечаем, поэтому `build_db.py` выбрасывает такие из выборки автоматически
(проверяя, что файл реально лежит в `web/media`).

Сжатие медиа — замерено, не оценено: видео 1024×576 @50 fps по ~7 МБ
превращаются в 480p @25 fps, картинки до 9 МБ — в ~85 КБ. Кодек — софтверный
libx264 CRF 27 preset slow: аппаратный videotoolbox с фиксированными 500 kbps
давал заметные артефакты на дорожных сценах. Средний клип ~0,95 МБ, суммарно
956 МБ — укладывается в лимит GitHub Pages (1 ГБ на сайт).

## Запуск

```bash
python3 scripts/build_db.py --category B   # xlsx -> SQLite + questions.json
scripts/serve.sh                           # http://localhost:8777
```

Медиа (нужен скачанный архив в `data/raw/`, ~9,5 ГБ):

```bash
python3 scripts/build_media.py --category B --jobs 4
```

Скрипт достаёт нужные файлы прямо из zip без полной распаковки, гонит `.wmv` → `.mp4`
через `h264_videotoolbox` и в конце печатает покрытие — сколько файлов из каталога
реально нашлось в архивах.

Архивы медиа:
- часть 1: https://www.gov.pl/pliki/mi/multimedia_do_pytan.zip (9,5 ГБ, от 12.02.2026)
- часть 2: `attachment/10d143bf-9e93-4d82-935d-48c89353d3ce` (32 МБ, от 02.04.2026)

## Режимы

- **Lekcja** — 12 вопросов, без таймера. Подбор: половина — то, что лечу
  неправильно, дальше новое, в конце повторение освоенного.
- **Egzamin** — точная симуляция WORD: 20 базовых + 12 специалистических,
  разнарядка баллов 10×3 + 6×2 + 4×1 и 6×3 + 4×2 + 2×1, итого 74; порог 68.
  Таймеры 20 с на чтение + 15 с на ответ (базовые) и 50 с (специалистические),
  возврата к вопросу нет.
- **Działy** — 12 тем; тема раскладывается эвристикой по ключевым словам,
  в каталоге министерства тематики нет.

## Дофаминовый слой

Цель — чтобы заходить хотелось каждый день, как в Duolingo.

- **XP**: +10 за правильный, +5 сверху при серии от 5, +10 при серии от 10,
  +25 за урок без ошибок, +50 за сданный пробный экзамен.
- **Дневная цель** (30/50/100/200 XP) — кольцо на главном экране, при
  выполнении становится золотым и стреляет конфетти.
- **Серия дней** 🔥 — растёт, когда цель дня взята; пропуск дня обнуляет.
- **Комбо** внутри урока, звук растёт по высоте с длиной серии.
- **Достижения** — 12 штук.
- **Дата экзамена** — обратный отсчёт и честный расчёт «сколько вопросов
  в день нужно, чтобы успеть»: (неосвоенные ÷ дней до экзамена).
- **Готовность** — доля вопросов в коробке Лейтнера ≥3, плюс отдельно
  скuteczность последних 100 ответов.
- Звук синтезируется через WebAudio (файлов нет), на телефоне — вибро.

Прогресс — в `localStorage` браузера, ключ `prawko.v2`.

## Выкатка

Живёт на **GitHub Pages**: https://flouzip.github.io/prawko/ (репозиторий
`FlouZip/prawko`, ветка `main`, корень).

```bash
scripts/push_github.sh      # заливка порциями по 150 файлов
```

Почему не Cloudflare Pages, хотя проект там заведён: у `wrangler` жёстко
зашито «3 пачки по 50 МБ параллельно», настроить нечем. На канале ~0,5 МБ/с
одна пачка идёт ~270 с при таймауте undici в 300 с, поэтому выгрузка
стабильно падала с `UND_ERR_HEADERS_TIMEOUT` на 3-10% файлов, и повторы не
помогали — прогресс не накапливается. Git шлёт коммитами, упавший `push`
повторяется отдельно, а уже отправленные коммиты остаются на сервере.

R2 отпал: активация требует привязки карты даже под бесплатный тир.

Лимиты GitHub Pages: сайт до 1 ГБ (у нас 956 МБ), 100 ГБ трафика в месяц,
10 сборок в час. Карта не нужна.

## Лицензия исходных данных

Отдельной лицензии на базу министерство не публикует, действует общее правило
портала gov.pl: тексты — **CC BY-SA 4.0**, фото и видео — **CC BY-NC-ND 4.0**.
Отсюда рамка проекта: бесплатно, без рекламы и подписки, с указанием источника.
Монетизировать эти медиа нельзя.
